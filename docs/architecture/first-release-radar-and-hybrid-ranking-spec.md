# iKanPP 自主「首发先锋雷达」与四大排序双轨智能融合置顶架构规范 (First-Release Priority & Hybrid Ranking Spec)

本文档确立了 iKanPP 平台超越爱壹帆（iyf.tv）的独立自主内容获取体系与全网首发抢跑工程规范。

---

## 1. 核心战略构想与行业破局 (Strategic Vision)

### 1.1 破除对爱壹帆的单向依赖
- **爱壹帆的天然局限**：
  爱壹帆走的是“保守型正规军”路线，由于坚持只收录正式流媒体数字发行源，导致**所有院线刚上映的热门大片（如《生化危机：爆发夜》等院线抢先版/枪版/TC版）存在长达 2 周到 2 个月的“绝对内容真空期”**。
- **搜索流量与用户增长的爆发窗口**：
  新片刚上映期，社交媒体（TikTok、抖音、B站、Twitter、小红书）爆发式传播引发全球华人在 Google、Bing 等搜索引擎上的指数级搜索浪潮。谁能在第一时间上线该片并被搜索引擎收录，谁就能垄断首发窗口期 **100% 的自然搜索流量与海量新用户留存**。
- **iKanPP 的双轨战略定位**：
  **“爱壹帆 4.3 万部高分精品库做坚实底座，自研首发先锋雷达做尖刀开路”**。
  我们绝不做单纯镜像，而是通过双轨融合引擎，既拥有爱壹帆庞大片库的厚重与口碑，又拥有全网首屈一指的“分钟级院线首发抢跑”速度！

## 3. 核心功能规范与落地细节

### 3.1 模块 A：全网首发雷达引擎 (`scripts/sync-first-release-radar.mjs`)
1. **多源并发嗅探**：
   - 每小时自动扫描光速资源、极速资源、暴风资源等骨干公网资源站最新 24 小时入库流；
   - 过滤条件：`vod_year >= 2025` 且名称或备注含有“抢先/TC/枪版/HD/正片”；
2. **片名纯化与华语内容安全门禁**：
   - 自动去除“抢先版/TC版/高清中字/国语/未删减/TS/CAM”等杂质，提取纯正官方标题；
   - 严格执行准则 12：日文平假名/片假名（无论汉字多少）坚决一票否决；全角波浪号 `～` 及成人低俗违禁词一票否决；汉字占比必须达到 40% 以上，杜绝纯外文与冷门外语条目入库；
3. **TMDB 官方 4K 物料自动对齐与建档**：
   - 内置简繁转换（`toTraditional`）与多级退避搜索机制；
   - 命中官方库后，拉取原版 4K 宽屏剧照 (`w1280`)、高清竖版海报 (`w500`)、正规剧情梗概、评分与演职员；
   - 为新片自动分配自增 `ikXXXXXX` 实体 ID，并同步写入 `entity:*`、`slug:*`、`title:*` 与 `index:all`；
4. **输出本地先锋片单缓存**：
   - 保存至 `.cache/first-release-pioneers.json`，供四大排序中枢与横轨智能调用。

### 3.2 模块 B：双轨智能融合排序中枢 (`scripts/sync-iyf-four-rankings.mjs`)
1. **时间排序先锋置顶铁律**：
   - 构建 `index:time_added:*`（添加时间）与 `index:time_updated:*`（更新时间）时，强制将首发先锋片单置顶在 Top 1~30 席；
   - 后面通过 `[...pioneerIds, ...orderedIds.filter(id => !pioneerSet.has(id))]` 顺延爱壹帆精品片单，永不覆盖冲掉先锋爆款；
2. **大厅列表 100% 满行整除与 Auto-Replenish 守护**：
   - 配合 `entity-kv.ts` 中的缺额自愈填补流水线，无论遇到任何下架或死链，恒定满 24 部，严丝合缝排满 6 列 4 行。

### 3.3 模块 C：全生命周期画质自动晋升机制 (Quality Auto-Upgrade)
1. **院线首发期**：
   - 角标标记为「抢先版/TC」，切片流接入公网第一手 TC 源，满足用户急迫观影需求；
2. **流媒体数字发行期**：
   - 1~2 个月后高清原盘流出，后台感知后自动切换超清源，角标自动升级为「4K超清」或「1080P」；
3. **SEO 权重 0 损耗与永久沉淀**：
   - 影视页面规范 URL 恒定不变（如 `/title/ik020581-生化危机-爆发夜`），首发期在 Google / Bing 积累的自然搜索第一位排名、反向链接与用户播放历史 **100% 永久保留**。

### 3.4 模块 D：全球搜索引擎闪电广播与 GitHub Actions 无人值守
1. **双轨广播矩阵**：
   - **IndexNow**：批量向 Bing 与 Yandex 推送最新 URL（HTTP 200），5 分钟内感知；
   - **Google Indexing API**：向 Googlebot 申请 Priority A 极速抓取通道；
2. **全自动闭环频次**：
   - 挂载于 `.github/workflows/sync-iyf-channels.yml`，**每小时整点全自动巡检执行（`0 * * * *`）**，形成“全网嗅探 ➔ 4K建档 ➔ 物理置顶 ➔ 全网广播”的无人值守闭环。
